# 大肥鱼视频设计规范（v1，2026-10-30）

> 从「大肥鱼日记」（dsh-bili-whale，745★）拆解 + `distinctive-ai-design` 的
> 「探索→定义→交付」方法论落地。模板不许自创样式，一律从这里取 token ——
> 模板感不是来自某个单独样式，而是来自缺乏意图和层级。

## 一、内容策略（比视觉值钱，先读这个）

学「大肥鱼日记」最该抄的不是 CSS，是它怎么**用真实运行日志讲故事**：

1. **系列化**：「大肥鱼日记 day0/day1/day2…」——每支是一个 Day，观众追更。
   模板顶栏的 Day 徽章就是为这个设计的。
2. **真事改编**：她真刷了 B站（「今天看了五条视频，只有一条让我笑了」）、
   真被评论轰炸（「我罢工了，评论不回了」）、真有 token 账本（「token 就是白饭」）。
   zhibo-auto 的日志/账本就是素材库，别编。
3. **悬念标题**：「两万人问我主人的钥匙是什么」——先抛数字和疑问。
4. **人设自洽**：所有梗从「一条住在电脑里的鱼」长出来（token=白饭、
   钥匙=主人的 API key），不要出戏玩别人的梗。
5. **克制**：日更≤1、发布时段随机化、AI 生成内容声明做进画面右上角（合规还加分）。

## 二、视觉 token（所有模板共用）

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#E7F0F9` | 底色（极浅蓝） |
| `--dot` | `rgba(255,255,255,.75)` | 点阵纹理（纸感） |
| `--ink` | `#14304A` | 正文（深蓝黑，不用纯黑） |
| `--border` | `#1E3A5F` | 粗描边（3~5px，漫画/像素风） |
| `--accent` | `#F5991C` | 强调橙（徽章/光标/音波/Day N） |
| `--card` | `#FFFFFF` | 气泡/信息卡底 |
| `--shadow` | `4px 6px 0 rgba(30,58,95,.28)` | 硬偏移阴影（不模糊！） |
| 字体 | 微软雅黑 Bold | 数字/标题，别用细体 |

配色铁律：**白卡 + 深蓝描边 + 橙强调 + 浅蓝底**，四样之外的颜色一律不加。
渐变、发光、模糊阴影禁用（硬阴影才有手作感）。

## 三、构图（竖屏 1080×1920）

```
┌──────────────────────────────┐
│ 大肥鱼 的 {日记名}  [Day N]  [AI 生成内容] │ ← 顶栏：标题+橙徽章+灰声明
│                              │
│ ┌────────────┐               │
│ │[大肥鱼] 气泡正文 ▌│        │  │ ← 左：对话气泡（占 2/3 宽）
│ │            音波 ▪▪▪│      │  │    右：皮套立绘常驻（微微浮动）
│ └────────────┘            🐋  │
│ ┌─ 信息卡（偶发）─┐           │
│ │ 2 万 / 80 斤    │           │ ← 数字大字 + 小字注释
│ └───────────────┘           │
└──────────────────────────────┘
```

- 立绘：`--border` 无、保持 PNG 原样，`filter: drop-shadow` 轻托底，浮动 ±14px / 2.4s
- 气泡：出现时 `translateX(-40px)→0` + 淡入 0.45s；当前气泡音波动画，已过气泡静止
- 信息卡：气泡流中**偶发**（一支视频 1~2 张），仿系统窗口：小标题栏 + 大数字 + 小注释

## 四、动效与节奏

- 气泡切换：按 TTS 时长**按字数加权分配**，每段 ≤24 字，一段说完换下一段
- 动效时长：入场 0.45s（ease-out）、浮动 2.4s 循环、音波 0.9s 循环——没有别的动画
- 结尾不 outro（参考账号就是说完即止），留 0.8s 持住最后一句
- 时长：60~110s/支（参考区间 74~109s，太短没叙事、太长掉完播）

## 五、评审流程（借 distinctive-ai-design）

新模板/改模板必须：渲染真实 mp4 → 抽关键帧 → 对照参考图自查
（构图/层级/减法三问：每个元素帮观众理解了什么？）→ 最多两轮改，每轮只改 1~3 个最伤的问题。
截图评审不通过不许投稿。
