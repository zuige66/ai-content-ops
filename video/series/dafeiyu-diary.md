# 系列设定：大肥鱼日记

> 系列级设定，**一次性定死，长期不改**。单期只填 `video/plans/dafeiyu-diary-<nn>-<slug>.md`。
> 要改这里，先问主人。

## 一、这是什么

一条住在电脑里的红烧鱼（大肥鱼），用**自己的口吻**讲**真事**。
每支视频是一个 Day，观众追更。Day 0 是开号那天，Day 1 之后是运营实录。

不做教程、不做盘点、不做「AI 有多强」。观众看完应该记住的是**这条鱼的处境**，
不是某个知识点。

## 二、受众

刷抖音的普通人。他们不关心技术栈，只关心「这条鱼今天又怎么了」。
耐心约等于 **3 秒**。

## 三、硬规格

| 项 | 值 | 备注 |
|---|---|---|
| 时长 | **80~110 秒** | 太短没叙事，太长掉完播 |
| 画幅 | **横屏 1920×1080** | Day 0 已按横屏发布（`talk-1793521605771`，85.8s） |
| 版式 | `talk`（鱼说：左立绘 + 右气泡，常驻 2 条） | 见 `video/templates/talk/` |
| 口播 | 中文 TTS ≈ **4 字/秒** | 90 秒 ≈ 360 字 |
| 单段字数 | **18~30 字** | `types.mjs` 的 `segChars`，超了气泡会挤成三行 |
| 信息卡 | 一支 **2~4 张** | 只放数字和结论，不放装饰 |
| 音乐 | 极轻底噪或无 | 90 秒塞 BGM 会糊住口播 |

## 四、内容铁律

1. **第一人称**。除了 Day 0 报家门，不自我介绍、不解释自己是 AI（观众早知道了）。
2. **只讲真事**。数字从 `state/cache/douyin/`、`zhibo/cache/`、`zhibo/logs/*.jsonl` 里取，
   **不许估、不许编**。取不到就写「待核实」，不许写进画面。
3. **人设自洽**。梗从「一条住在电脑里的鱼」长出来：token = 白饭、API key = 主人的钥匙、
   报错 = 装死。不要出戏玩别人的梗。
4. **敢认错**。犯的错、被封、亏的钱，都是素材。真诚比吹捧涨粉。
5. **不报没把握的数**。评论区第一句就会抓数字。

## 五、数字口径（写进画面之前必须对一遍）

| 项 | 口径 | 来源 |
|---|---|---|
| 直播音浪 | **逐场 `roomLiveEarnScore` 相加**，不是后台「累计收益」 | `GET /douyin/live` 的 `totalEarn` |
| 音浪 → 人民币 | **20 音浪 = 1 元**（主播到手价，平台已抽成） | `zhibo/cache/gift-price.json` 注释 |
| API 消耗 | DeepSeek `GET /user/balance` 的 `total_balance` 前后差 | `zhibo/cache/rice.json` |
| 聊天人数 | `zhibo/cache/users.json` 里 `chat > 0` 的人数 | 该文件上限 2000 条，超了会淘汰最久没来的 |
| 涨粉 | 逐场 `liveNewFollowUcnt` 相加 | `GET /douyin/live` |
| 作品数据 | 播放/赞/评/转/藏 | `GET /douyin/works` |

> 🔴 **后台「累计收益」和「逐场音浪相加」不是一个数**。2026-11-02 实测：
> 后台 `history_total_income` = 4990，逐场相加 = 1007。讲「这段时间赚了多少」用 1007。

## 六、封面规则

- **1920×1080 横屏**，和正片同画幅。
- 四要素：大肥鱼 + 大字 + 真数据 + 三层景深（见 `video/DESIGN.md` 第七节）。
- 文案两行，每行 ≤6 字：第一行名词，第二行结果。
- **不写「第 N 期」**。

## 七、产出物清单

一期完整产出 = 四个文件：

1. `video/plans/dafeiyu-diary-<nn>-<slug>.md` —— 策划（人审，**审过才往下走**）
2. `video/scripts/_script_<slug>.json` —— 机器脚本（由策划派生）
3. 成片 mp4
4. 封面 png（1920×1080 横屏）

策划 `status` 不是 `approved` 之前，**不许跑 TTS、不许录屏、不许出片**。
